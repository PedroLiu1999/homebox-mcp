# Homebox MCP — Logo & Usage Guide

The **Homebox MCP** logo ("BoxBot") extends the official Homebox [`lilbox.svg`](https://hay-kot.github.io/homebox/assets/img/lilbox.svg) mark (originally designed by `@lakotelman`) with an AI visor and antenna node.

## Files

- `homebox-mcp-symbol.svg` — Primary full-colour symbol (`256×256` viewBox)
- `homebox-mcp-symbol-small.svg` — Small-size cut for `16–24 px` toolbars and favicons (bolder eyes & antenna)
- `homebox-mcp-horizontal.svg` — Primary horizontal lockup (`840×256` viewBox)
- `homebox-mcp-stacked.svg` — Stacked lockup for README headers & social cards (`420×340` viewBox)
- `variants/` — Exported `black`, `white`, `mono` (`#567f67`), `square`, `favicon`, `app-icon`, and web icon set (`favicon.ico`, PNG icons, `site.webmanifest`)
- `png/` — Rendered PNGs (`512px` / `1200px`)

## Colour Palette

| Role | Hex | Usage |
|---|---|---|
| **Homebox Sage** | `#567f67` | AI visor screen, antenna node, `"MCP"` wordmark accent, mono brand variant |
| **Box Light Grey** | `#dadada` | Outer box body & front-left flap |
| **Box Shadow Grey** | `#808080` | Open box interior & back-right flap |
| **Outline / Ink** | `#000000` / `#111111` | Box linework & `"Homebox"` wordmark |
| **Visor Eyes** | `#ffffff` | Circular AI eyes inside the sage visor |

## Clear Space & Minimum Size

- **Clear space:** Leave at least **25% of the symbol width** clear on all sides.
- **Minimum sizes:**
  - Symbol: `16 px` digital (use `homebox-mcp-symbol-small.svg` or `favicon.ico` below `32 px`)
  - Horizontal lockup: `140 px` wide
- **Typography:** Wordmark uses `Inter` (Bold `700` for `Homebox`, Regular `400` for `MCP`) with system-ui fallback. Convert `<text>` to outlines if distributing for print/vector cutting.
